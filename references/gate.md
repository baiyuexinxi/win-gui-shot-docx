# Gate 清单：截图入口闸门

> 用法：每开始一个"要往文档里放界面图"的任务，先填这份清单再动手。
> **强制项：A1 / A2 / A3**（任一不过 → 直接否决，不许降级）。
> **记录项：A4 / A5**（照常评估、照常写进日志，但**不阻断**，失败只在报告末尾打一行 WARN）。

**任务**：________________　**目标软件**：________________　**计划图数 n**：______　**日期**：__________

---

## A1 介质必要性　`强制`　否决码 `DENY_TEXT`

- [ ] 我能写出这一句话（必填）：
      **claim_it_proves**：____________________________________________
- [ ] 这句话**不能用数值或表格等价表达**

**判据**：两条都成立才算过。第一条写不出来 → 直接否决；第二条不成立 → 否决。
**反例**：把控制台的 `[1] 62 10` 截成图。它的全部信息就是两个数，一句话就能写完，图是纯噪声。

---

## A2 通道优先　`强制`　否决码 `DENY_CHANNEL`

- [ ] 目标软件**不在**下面这张通道表里

| 目标 | 更优通道 |
|:---|:---|
| 浏览器页面 | `dsh_browser_*`（CDP），可读 DOM、可点击、截图更稳 |
| 命令行 / 解释器 | 直接重定向 stdout，文本最可靠 |
| 绘图（matplotlib/ggplot/R base） | 库自己导出 PNG/PDF，清晰度与体积都更好 |
| Office 文档 | 直接生成 docx/xlsx，不必截自己的屏幕 |
| 有官方导出功能的软件 | 用它自己的 Export |

**判据**：命中任意一行 → 否决，改用该通道。

---

## A3 判据可枚举　`强制`　否决码 `DENY_NO_ORACLE`

- [ ] **anchor**（≥8 字符的 ASCII 片段或数字串）：______________________
- [ ] **anchor_line_hint**（大致在第几行，供 L2 决定搜前 N 行还是全图）：______

**判据**：锚点存在且可定位。写不出锚点 = 无法判断截对没截对 = 闭眼交付，否决。
**反例**：想截一张 Krita 画布效果图——里面没有可枚举的文本，只能人工看。

---

## A4 环境可用　`记录`　码 `DENY_NO_DESKTOP`

- [ ] `quser` 显示会话为 **Active**（不是 Disc）
- [ ] 目标窗口能被 `EnumWindows` 命中（不是 0 个）

**不通过时**：仍然继续尝试，但在报告末尾打 `WARN DENY_NO_DESKTOP`。
常见成因：锁屏、RDP 断开、目标软件根本没启动。

---

## A5 规模经济　`记录`　码 `DENY_TRIVIAL`

- [ ] **n ≥ 3**

**不通过时**：照样做，但报告里注明"n 较小，本可用手截，成本更高"。
今天这次 n=12 且重采 4 轮 → 通过；若只有 1 张图，就不值得起流水线。

---

## 判定合成

```
A1、A2、A3 全部通过            → ALLOW，进入采集
任一强制项失败                 → DENY <原因码>，停止，不产出任何图
A4、A5 失败                    → 照常执行，末尾附 WARN 行
```

---

## 两个填好的示范

**示范一：本次实验五**

| 项 | 值 |
|:---|:---|
| A1 claim | 证明该题代码真实在 RStudio 中执行并产生了对应输出 |
| A2 | RStudio 原生 GUI，不在通道表内 → 通过 |
| A3 anchor | `library(magrittr)`，第 2 行附近 → 通过 |
| A4 | 会话 Active、窗口命中 → 通过 |
| A5 | n = 12 → 通过 |
| **结果** | **ALLOW** |

**示范二：假设有人要截"浏览器里的 Jupyter 输出"**

- A1 通过（证明确实运行过）
- A2 **失败**：页面在浏览器里，应走 CDP → `DENY_CHANNEL`
- 结论：改用浏览器通道，不启截图流程

**示范三：假设要截"Krita 画的一张图"**

- A1 通过
- A2 通过（无更好通道）
- A3 **失败**：画布里没有可枚举文本 → `DENY_NO_ORACLE`
- 结论：人工截，或让软件自己导出图片

---

## 与脚本的对应关系

- 规则表：`gate.json`（含 `enforce: ["A1","A2","A3"]`）
- 评估器：`gate.ps1 -GateFile gate.json -AnswersFile answers.json`
- 输出：`VERDICT=ALLOW` 或 `VERDICT=DENY A1:DENY_TEXT,...`，外加 `PASS=` / `WARN=` / `NOTE`
